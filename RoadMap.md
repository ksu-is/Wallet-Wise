Wallet Wise – Project Roadmap

Sprint 1: Research and Initial Development (Weeks 1–2)

Goal: Research existing budgeting applications, plan the program structure, and begin developing the main features.

Week 1: Research and Planning

Research existing Python budgeting and savings tracker repositories.

Review a related GitHub repository and document its features.

Identify the main features needed for Wallet Wise.

Plan the program's menu and user input options.

Week 2: Initial Development

Create the main Python file and interactive program menu.

Develop an income entry function.

Develop an expense tracking function.

Create a function to calculate the remaining balance.

Test the initial features and document any errors.

Future Development

Add a savings goal calculator.

Create a spending summary.

Add expense categories.

Improve input validation and error handling.

Test the completed program and fix errors.

Update project documentation.

Expected Sprint Outcome

By the end of the first two weeks, Wallet Wise should have a working program structure, basic income and expense tracking, and a balance calculator.
